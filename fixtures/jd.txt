全栈工程师（AI 应用方向）

公司简介
我们是一家专注于 AI for Science 的科技公司，核心产品为科学智算平台，通过自然语言驱动的
自动化科研工作流服务科研场景。团队由来自国内一流高校的研发人员组成。

岗位职责
1. 负责 AI 应用产品的前后端开发，参与从需求到上线的完整链路；
2. 设计并实现与大模型交互的服务端接口，包括 Prompt 编排、结果结构化与失败重试；
3. 建设面向科研人员的 Web 界面，保证交互流畅与结果可读；
4. 参与工程化建设：CI/CD、监控告警、日志与错误追踪。

任职要求
1. 本科及以上学历，计算机相关专业，3 年以上开发经验；
2. 熟练掌握 TypeScript / JavaScript，熟悉 Node.js 服务端开发；
3. 熟悉 React 或 Vue 等主流前端框架，具备完整项目落地经验；
4. 熟悉 MySQL / PostgreSQL 等关系型数据库，了解 Redis 缓存设计；
5. 有 LLM 应用开发经验，了解 OpenAI API、Prompt Engineering、RAG 等技术；
6. 熟悉 Docker，了解基本的 CI/CD 流程。

加分项
1. 有 Python 数据处理经验（Pandas / NumPy）；
2. 了解向量数据库（Milvus / Pinecone / Faiss）；
3. 有开源项目贡献或技术博客输出；
4. 有科研或高性能计算相关业务背景。
